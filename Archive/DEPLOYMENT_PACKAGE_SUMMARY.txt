HOW TO USE THIS PACKAGE
================================================================================

1. TRANSFER TO TARGET ENVIRONMENT
   ─────────────────────────────────
   Email, USB, or network copy the ZIP file:
   
   📧 Email: ZertoCompliance_DeploymentPackage.zip (only 144 KB!)
   💾 USB: Copy to thumb drive
   🌐 Network: Place on file share

2. EXTRACT ON TARGET MACHINE
   ─────────────────────────────────
   Right-click ZIP → Extract All
   
   Or use PowerShell:
   Expand-Archive -Path ZertoCompliance_DeploymentPackage.zip -DestinationPath C:\Temp\

3. READ START_HERE.TXT
   ─────────────────────────────────
   Open START_HERE.txt for quick instructions

4. INSTALL (ONE COMMAND!)
   ─────────────────────────────────
   Right-click PowerShell → Run as Administrator
   
   cd ZertoComplianceTool
   powershell -ExecutionPolicy Bypass -File Install-ZertoComplianceLauncher.ps1

5. RUN THE APPLICATION
   ─────────────────────────────────
   After installation:
   
   Method 1: Start Menu → "Zerto Compliance Launcher"
   Method 2: "C:\Program Files\ZertoCompliance\ZertoComplianceLauncher.exe"
   Method 3: Double-click ZertoComplianceLauncher.exe in the extracted folder!
