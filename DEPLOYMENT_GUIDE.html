📖 Overview

The Zerto Compliance Tool is a comprehensive assessment utility designed to evaluate your Zerto disaster recovery and business continuity infrastructure against compliance standards. It provides detailed reports on:

  • DR Testing Effectiveness (40% weight)
  • VM Coverage & Protection (30% weight)
  • Cyber Resilience via Long-Term Retention (30% weight)
  • Site Configuration & Certificate Management
  • Multi-site replication analysis
  • Recovery testing metrics from the last 6 months
Current Version: 2.1.0 (Released: December 25, 2025)
New in v2.1.0: Secondary credentials support, multi-site configuration, improved score explanation modals, duplicate site filtering

📋 System Requirements & Prerequisites

Windows Server/Workstation Requirements

Operating System: Windows Server 2016+ or Windows 10/11 Pro/Enterprise
.NET Runtime: .NET 8.0 Desktop Runtime (WindowsDesktop.App). The setup script can install this automatically.
PowerShell: PowerShell 5.1+ (included with Windows Server 2016+)
Disk Space: Minimum 500 MB for installation + output reports
Network Access: HTTPS connectivity to Zerto ZVMA on port 443 (Zerto 10.x Linux) or port 9669 (Zerto 9.x Windows)
User Privileges: Local Administrator rights on Windows system

Zerto Environment Requirements

Zerto Version: 8.5 or later
ZVMA Access: Valid credentials with read access to Zerto APIs
Multi-Site Support: Optional - can analyze single or multiple sites

SSL/TLS Certificate Considerations

⚠️ Important: The tool can operate in "Lab Mode" (SSL verification disabled) for testing with self-signed certificates. For production use, ensure proper SSL certificates are installed on ZVMA.
Default Behavior: Strict SSL verification enabled
Lab Mode: Available checkbox to disable SSL verification (not recommended for production)

Network & Firewall

Outbound HTTPS: Port 443 (Zerto 10.x Linux) or Port 9669 (Zerto 9.x Windows) to primary Zerto ZVMA
Secondary Site: Port 443 (Zerto 10.x) or Port 9669 (Zerto 9.x) to secondary Zerto ZVMA (if multi-site)
⚠️ Zerto 10.x Architecture Change: Zerto 10.x on Linux uses standard HTTPS port 443 for both GUI and API access via Keycloak authentication. Port 9669 is no longer required. The tool automatically detects the correct endpoints.
DNS Resolution: Ability to resolve ZVMA hostnames or use IP addresses

🔧 Installation Instructions

Pre-Installation Checklist

1

Verify .NET Runtime

Check if .NET 8.0 is installed on the target machine. Open PowerShell as Administrator and run:

dotnet --list-runtimes

If you see Microsoft.WindowsDesktop.App 8.0.x in the output, .NET is installed. If not, proceed to Step 2.

2

Install .NET 8.0 Runtime (if needed)

If .NET is not installed, run the included installer:

cd "C:\Path\To\Package"
powershell -ExecutionPolicy Bypass -File dotnet-install.ps1

This script will download and install .NET 8.0 from Microsoft's servers. Installation takes 2-5 minutes.

⚠️ Note: Requires internet connectivity during installation
3

Run the Installer

Execute the deployment installer with Administrator privileges:

powershell -ExecutionPolicy Bypass -File Install-ZertoComplianceLauncher.ps1

This installer will:

  • Create directory: C:\Program Files\ZertoCompliance\
  • Copy all required files
  • Create desktop shortcut (optional)
  • Register the application
4

Verify Installation

Confirm files are in place:

ls "C:\Program Files\ZertoCompliance\"

You should see:

ZertoComplianceLauncher.exe ZertoComplianceNew.ps1 [Other supporting files]
✓ Installation Complete! You can now launch the tool from the Start Menu or run: C:\Program Files\ZertoCompliance\ZertoComplianceLauncher.exe

Alternative: Manual Installation

If you prefer manual installation without the installer script:

A

Create Directory

mkdir "C:\Program Files\ZertoCompliance"
B

Copy Files

Copy-Item "C:\Path\To\Package\*" -Destination "C:\Program Files\ZertoCompliance\" -Force
C

Create Shortcut

Right-click ZertoComplianceLauncher.exe → Send to → Desktop (create shortcut)

⚙️ Configuration & First Use

Launching the Application

1

Start the Tool

Double-click the desktop shortcut or run:

"C:\Program Files\ZertoCompliance\ZertoComplianceLauncher.exe"

Basic Configuration

2

Enter Source Site (Primary ZVMA)

Label: Source Site
Input: IP address or hostname of your primary Zerto ZVMA

Example: 192.168.111.20 or zvma-prod.corp.local

3

Enter GUI User Credentials

Label: Zerto GUI User Name
Default Example: admin

Enter the username with API read access to your Zerto ZVMA. This is typically:

  • admin (default admin user)
  • Service account username (if configured)
  • Domain user (e.g., zerto-svc)

Password: Enter the corresponding password (stored securely, never logged)

4

Configure Secondary Site (Optional)

Label: Secondary Site
Input: IP or hostname of secondary Zerto ZVMA

Leave blank if you only have a single site. If you have multiple replication targets:

  • Check: "Secondary site has different credentials" (if needed)
  • Enter secondary site credentials if different from primary
5

Configure Additional Sites (3+)

If you have more than 2 sites:

  • Check: "Additional sites (3+)"
  • Enter comma-separated list: 192.168.333.20,192.168.444.20
6

Configure Advanced Options

Lab Mode (Skip SSL Verification):

  • Enable only if testing with self-signed certificates
  • NOT recommended for production

Evaluate Cyber Resilience (LTR):

  • Check this to include Long-Term Retention (LTR) vault lock status in scoring
  • 25% weighting in overall compliance score

Create Scheduled Task:

  • Check to schedule recurring compliance scans
  • Select frequency: Daily, Weekly, or Monthly
  • Default: 2:00 AM UTC
7

Select Output Folder

Default: Documents\ZertoCompliance

Click "Browse..." to change location. Each scan creates a timestamped folder with:

  • Report_TIMESTAMP.html - Interactive compliance report
  • MANIFEST.json - Scan metadata and configuration
  • LOG.txt - Detailed execution log
  • SUMMARY.txt - Text summary of findings
  • RecoveryReports/ - Recovery test data from last 6 months

Running Your First Scan

8

Execute Scan

Click the green "Run Now" button to start the assessment.

Status updates appear in real-time:

  • Connecting to ZVMA...
  • Retrieving configuration...
  • Analyzing VPGs and VMs...
  • Generating report...
  • ✓ Compliance scan completed successfully!

Typical scan duration: 30 seconds to 2 minutes depending on environment size

9

View Completion Dialog

Upon completion, a success dialog appears with two options:

  • Open HTML Report: Opens the compliance report in your default browser
  • Open Folder: Opens the output directory in File Explorer
✓ Report generated: ZertoCompliance_192.168.111.20_20251225_160000/Report_20251225_160000.html

Understanding the Report

The HTML report includes:

Section Description
Dashboard Cards Quick overview - click any card to see breakdown (effectiveness vs weighted contribution)
Zerto Sites Primary and recovery site configurations, versions, certificate expiration
VPG & VM Information Count of VPGs, protected VMs, unprotected VMs, coverage percentage
DR Test Summary Recovery test results from last 6 months
Controls Mapping Which compliance controls are met

✨ Key Features

Scoring Methodology

The compliance score (0-100%) uses dynamic weights. When Cyber Resilience (LTR) is evaluated, the standard weights apply. When LTR is not evaluated, its weight is redistributed to DR Testing and VM Coverage.

Category Weight (LTR On) Weight (LTR Off) Measured By
DR Testing 40% ≈57.14% % of VPGs tested in last 6 months
VM Coverage 30% ≈42.86% % of VMs protected by Zerto
Cyber Resilience 30% 0% (not scored) % of LTR VPGs with vault locks enabled

Multi-Site Support

  • Single-site analysis (primary ZVMA only)
  • Two-site analysis (primary + secondary with optional different credentials)
  • Multi-site analysis (3+ sites in comma-separated format)
  • Automatic detection of recovery targets from VPG configurations
  • Duplicate site filtering - primary site never appears in recovery list

Report Generation

  • Interactive HTML5 report with click-through modals
  • Color-coded scoring (green=compliant, yellow=partial, red=at-risk)
  • Timestamped filenames for easy version tracking
  • JSON manifest for programmatic access
  • Machine-readable CSV output format available

Lab Mode Capability

  • SSL verification bypass for testing environments
  • Self-signed certificate support
  • Checkbox clearly marked in red for safety

Security & Privacy

  • Passwords never logged or stored in reports
  • HTTPS only communication with ZVMA
  • Credentials validated per-site independently
  • No external cloud connectivity - reports stored locally

Support for Zerto Features

  • Long-Term Retention (LTR) vault lock status
  • Recovery test metrics and analytics
  • Certificate expiration monitoring
  • VPG test history (6-month lookback)

🔧 Troubleshooting

Common Issues & Solutions

Issue: ".NET runtime not found"

Solution: Install .NET 8.0 Desktop Runtime

powershell -File dotnet-install.ps1

Or download from: https://dotnet.microsoft.com/download/dotnet/8.0

Issue: "Authentication failed" when connecting to ZVMA

Verify:

  • ZVMA IP/hostname is correct and reachable
  • Username and password are correct
  • Port 9669 is accessible from this machine
  • Firewall rules allow outbound HTTPS to ZVMA
  • User has API read permissions in Zerto

Test connectivity:

Test-NetConnection -ComputerName 192.168.111.20 -Port 9669

Issue: "SSL certificate validation failed"

For testing environments: Enable "Lab Mode" checkbox

For production: Ensure ZVMA has valid SSL certificate installed

Check certificate:

openssl s_client -connect 192.168.111.20:9669 -showcerts

Issue: "Report not found after scan completes"

Check:

  • Output folder path is writable
  • Disk space available (minimum 100 MB)
  • Verify scan completed successfully in output window
  • Check LOG.txt file for errors

Manually locate report:

dir "C:\Users\[YourUsername]\Documents\ZertoCompliance"

Issue: "Secondary site authentication fails but primary works"

Check:

  • Secondary site IP/hostname is correct
  • Secondary site uses same credentials as primary (if checkbox unchecked)
  • If different credentials needed, check "Secondary site has different credentials"
  • Verify network connectivity to secondary ZVMA

Log File Analysis

For detailed troubleshooting, examine the LOG.txt file in your output folder:

C:\Users\[YourUsername]\Documents\ZertoCompliance\
  └── ZertoCompliance_192.168.111.20_20251225_160000\
      └── LOG.txt

Look for:

  • ERROR or EXCEPTION messages
  • Failed API calls with response codes
  • Connection timeout messages
  • Permission-related errors

Contacting Support

If issues persist, gather the following and contact support:

  • LOG.txt file from the failed scan
  • MANIFEST.json (contains no sensitive data)
  • Screenshot of error message with timestamp
  • ZVMA version (Help button → email to aaron.lastoff@hpe.com)

🛠️ Troubleshooting

Common Issues & Fixes

1

EXE does not open

If the launcher appears to do nothing when executed:

  • Run the environment setup first:
    powershell -ExecutionPolicy Bypass -File .\Setup-Environment.ps1
  • Confirm the Windows Desktop runtime is installed:
    & "$env:ProgramFiles\dotnet\dotnet" --list-runtimes
    Ensure Microsoft.WindowsDesktop.App 8.0.x is listed.
  • Check the launcher log for startup errors:
    Get-Content "$env:TEMP\ZertoComplianceLauncher.log" -Tail 50
  • Try launching elevated:
    Start-Process "C:\Program Files\ZertoCompliance\ZertoComplianceLauncher.exe" -Verb RunAs
2

.NET Runtime Missing

If you see errors related to .NET, run the included installer or download from Microsoft:

powershell -ExecutionPolicy Bypass -File dotnet-install.ps1

Or visit .NET 8.0 Downloads.

3

Authentication Failures

Ensure that your ZVMA IP/hostname is correct, your credentials are valid, and that the correct port is reachable (443 for Zerto 10.x Linux, 9669 for Zerto 9.x Windows).

4

SSL Certificate Issues

If you encounter SSL/TLS certificate errors during testing or lab use, you can enable Lab Mode (skip SSL verification) in the launcher. For production, install valid certificates on ZVMA.
